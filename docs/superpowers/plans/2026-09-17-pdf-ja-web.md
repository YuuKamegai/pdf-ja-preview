# PDF Japanese Preview Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. このセッションでは単一エージェントで順に実行する。実装開始時に superpowers:using-git-worktrees を適用し、既存の隔離環境を確認する。

**Goal:** 英語の学術論文・一般文書 PDF を、原文と対応する日本語で左右表示するローカル Web アプリを作る。

**Architecture:** PDF.js で原文を先に表示し、Node サーバーから専用 Python ワーカーの Docling へ全文抽出を依頼する。座標と読み順を保持した中間形式を返し、サーバー全体で並列度 1 の Ollama 翻訳を行う。ブラウザへ SSE で状態を配信し、ページと領域で原文・訳文を対応づける。

**Tech Stack:** Node.js 24、TypeScript、PDF.js、esbuild、Python 専用仮想環境、Docling、Ollama、node:test、pytest、Playwright。

**Spec:** `docs/superpowers/specs/2026-09-17-pdf-ja-web-design.md`（本計画と一緒に読む）。

## Global Constraints

- 初期版は文字選択可能な一段組み・二段組み PDF を対象とする。
- 表のセル翻訳、図中の文字置換、数式の再組版、翻訳済み PDF の出力、OCR、URL からの取得は初期版の対象外。
- 抽出は初期版では CPU を使用し、Ollama が使用する GPU のメモリと競合しにくくする。
- 翻訳並列度は 1。現在ページ、次ページ、残りの文書順に未実行ジョブを優先する。
- サーバーは `127.0.0.1` にのみバインドし、起動時にブラウザを開けるコマンドを提供する。
- 上限は初期値 50 MiB・300 ページ。超過は処理開始前またはページ数判明時に明示して拒否する。
- 抽出同時実行は 1。待機・実行・失敗を区別し、抽出タイムアウトは初期値 10 分とする。
- 既存 Markdown 拡張の既定動作は変更しない。共有部分の変更は既存テストでも検証する。
- 文書・訳文をリポジトリへ保存しない。テストに使う実文書は配布条件を確認し、研究者提供資料を勝手に fixture 化しない。
- 原文を扱う実行時は CDN・外部サービスを使わない。依存・モデル取得はセットアップ時のみ。
- チェックボックスは証拠がある工程だけ完了にする。モック成功、実 Docling 成功、実 Ollama 成功、翻訳品質確認を区別する。

```ts
export type Kind = 'heading'|'paragraph'|'list'|'caption'|'footnote'|
  'picture'|'table'|'formula'|'reference'|'furniture';
export interface Region {
  page: number; box: [number, number, number, number];
  charRange?: [number, number]; // 原文の終端排他
}
export interface PdfBlock {
  id: string; kind: Kind; order: number; source: string;
  headingContext: string; translatable: boolean; regions: Region[];
  relatedIds: string[];
}
export interface PdfPage {
  number: number; width: number; height: number; rotation: number;
  status: 'ok'|'no-text'|'failed';
}
export interface PdfDocument {
  schema: 'pdf-document.v1'; hash: string;
  extractor: {version: string; configHash: string};
  pages: PdfPage[]; blocks: PdfBlock[]; warnings: string[];
}
export type BlockStatus = 'source'|'queued'|'translating'|'translated'|'error';
export interface TranslationState {

  ja?: string; error?: {code: string; message: string};
}
export function parseDocument(input: unknown): PdfDocument;
export function normalizedToPdf(
  box: Region['box'], view: [number, number, number, number]
): [number, number, number, number];
```
